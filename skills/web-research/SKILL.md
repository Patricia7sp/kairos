# Web Research Skill

## When to Use
Use quando o usuário solicitar informações recentes ou buscas de documentação externa.

## Prerequisites
- Conexão ativa com a internet.

## How to Run
Use a ferramenta `web_search` passando a query desejada.

## Quick Reference
- `web_search(query="termo de busca")`

## Procedure
1. Formular query precisa
2. Executar web_search
3. Sintetizar os resultados para o usuário

## Pitfalls
- Evite queries vagas ou muito genéricas.

## Verification
Valide se as respostas obtidas atendem a dúvida do usuário.
